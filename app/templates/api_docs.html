API pública sin autenticación para acceder a los datos del observatorio.

Endpoint Base
https://sapogis.ifop.cl/hdo/api/v1/
Endpoints Disponibles
EndpointMétodoDescripciónParámetros
/statusGETEstado del sistema-
/enosGETÚltimos indicadores ENOSlimite (default 60)
/enos/historicoGETSerie histórica ENOSdesde, hasta (YYYY-MM-DD)
/surgenciaGETDatos de surgencia costerazona, limite (default 100)
/hcsGETIndicadores H. Currentlimite (default 60)

Ejemplos de uso
JSON (default):
curl https://sapogis.ifop.cl/hdo/api/v1/enos
CSV:
curl https://sapogis.ifop.cl/hdo/api/v1/enos?formato=csv
Rango de fechas:
curl "https://sapogis.ifop.cl/hdo/api/v1/enos/historico?desde=2020-01-01&hasta=2024-12-31"
